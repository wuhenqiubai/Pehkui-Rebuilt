# Changelog

## v3.8.4 (2026-08-06)

- **Restored step height scaling** — all versions. Step height now scales with entity scale, so smaller entities can climb shorter blocks and movement feels noticeably smoother.
- **Fixed view bobbing speed** — Minecraft 1.21.2 and newer. Walk distance is no longer scaled when computing view bobbing, so large entities no longer bob too fast.
- **NeoForge jar naming** — NeoForge builds now include the Minecraft version in the jar filename (e.g. `pehkui-rebuilt-nf-3.8.4+1.21.2.jar`).
